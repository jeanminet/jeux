# Project Rules

0. The rules are written in this `RULES.md` file.
1. Every game must compile into a single self-contained HTML file with no external dependencies.
2. Keep the code as simple and approachable as possible.
3. UX stays minimalist: large readable typefaces, restrained colors, and a full-screen layout that remains consistent between games.
4. Opening a game always starts it in a fresh state—no persistence between sessions.
5. Creating a new game should require only the minimal information specific to that game.
6. Each game needs a clear notion of progression from easy to hard, surfaced through a shared progression component.
